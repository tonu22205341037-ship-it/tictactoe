# 🎮 Tic Tac Toe Game

A simple, interactive, and user-friendly Tic Tac Toe game designed for two players. Players take turns marking X and O on a 3×3 grid. The first player to get three matching symbols in a horizontal, vertical, or diagonal row wins the game.

## ✨ Features

- Two-player gameplay (X and O).
- Interactive 3×3 game board.
- Automatic turn switching.
- Winner detection.
- Draw detection.
- Restart and reset game functionality.
- Simple and user-friendly interface.
- Responsive design.

## 🛠️ Technologies Used

- **HTML5** – Structure of the game.
- **CSS3** – Styling and layout.
- **JavaScript** – Game logic and functionality.

## 🎯 How to Play

1. Open the game in your web browser.
2. Player 1 starts with X.
3. Player 2 plays with O.
4. Players take turns selecting empty cells.
5. The first player to match three symbols horizontally, vertically, or diagonally wins.
6. If all nine cells are filled without a winner, the game ends in a draw.
7. Click the restart button to play again.
